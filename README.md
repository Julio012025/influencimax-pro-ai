## 🌟 Visão Geral

O **InfluenciMax Pro AI** resolve o maior gargalo do marketing de influência moderno: a falta de previsibilidade e automação de ponta a ponta. A plataforma integra desde a curadoria inteligente e análise de reputação de creators até a simulação preditiva de ROI, contratos digitais com assinatura integrada e relatórios executivos em PDF/Excel.

---

## 🚀 Principais Funcionalidades

### 1. 🎯 Diretório & Discovery de Criadores
- Filtros por nicho (Tech, Moda, Fitness, Gaming, etc.), plataforma, engajamento e taxa de fraude/autenticidade.
- Score de reputação algorítmico e métricas de audiência qualificadas.

### 2. 🤖 IA Co-pilot & Briefing Inteligente
- Geração instantânea de roteiros e briefings técnicos de campanhas via IA generativa.
- Análise de consistência de marca, tom de voz e sugestões de gatilhos mentais.

### 3. 📈 Simulador Preditivo de ROI
- Modelagem de cenários (Conservador, Base, Otimista) antes de alocar verba de mídia.
- Estimativas dinâmicas de alcance projetado, CPC, CPA e faturamento esperado.

### 4. ⚡ Automation Studio
- Criação e disparo de réguas de relacionamento com criadores via WhatsApp Business API e E-mail.
- Automação de lembretes de prazos de entrega e validação de peças publicitárias.

### 5. 💳 Checkout & Gestão de Gateways
- Suporte a múltiplos gateways de pagamento (Stripe, Asaas, Mercado Pago, Pagar.me).
- Split de pagamentos automático com emissão de recibos e controle de comissões.

### 6. 📊 Analytics, Relatórios Executivos & Exportação
- Dashboards com KPIs de engajamento, conversões, taxa de cliques e faturamento.
- Exportação com um clique para relatórios executivos em **PDF** e planilhas **Excel**.

## 🛠️ Stack Tecnológica

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons.
- **Charts & Vis**: Recharts para visualizações preditivas e analíticas.
- **Exportação**: jsPDF, xlsx.
- **Backend / Dev Server**: Node.js, Express, TSX, Vite.

## 📦 Como Executar Localmente

### Pré-requisitos
- Node.js 18+ ou superior
- npm / yarn / bun

### Instalação

```bash
# Clone o repositório
git clone https://github.com/SEU_USUARIO/influencimax-pro-ai.git

# Acesse a pasta do projeto
cd influencimax-pro-ai

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

Abra seu navegador em `http://localhost:3000`.
